# KERNX BAU Website — GitHub Root Version

Diese Version ist für den direkten Upload in das Stammverzeichnis des GitHub-Repositories vorbereitet.

Alle Dateien — HTML, Logo und Bilder — liegen auf derselben Ebene. Es muss kein `assets`-Ordner angelegt werden.

## Direkt hochladen
Alle Dateien dieses Ordners gemeinsam in den Branch `main` hochladen und vorhandene gleichnamige Dateien ersetzen.

## Enthalten
- `index.html`
- `impressum.html`
- `datenschutz.html`
- `CNAME`
- `.nojekyll`
- Logo und sämtliche Website-Bilder

## Kontaktformular
Das Formular öffnet eine vorbereitete E-Mail an `contact@kernxbau.de`. Es findet kein serverseitiger Formularversand statt.

## Vor Veröffentlichung
Die HRB-Nummer in `impressum.html` ergänzen.
