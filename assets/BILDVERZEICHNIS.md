
## Ein Bild austauschen

Dateinamen **nicht** ändern — sie stehen im Code. Stattdessen die drei Varianten überschreiben:

```bash
convert neu.jpg -auto-orient -resize '1100x1100>' -strip -quality 58 assets/img/bau/14-graben-gehweg-1280.webp
convert neu.jpg -auto-orient -resize  '800x800>'  -strip -quality 62 assets/img/bau/14-graben-gehweg-800.webp
convert neu.jpg -auto-orient -resize  '800x800>'  -strip -quality 62 assets/img/bau/14-graben-gehweg-800.jpg
```

Danach prüfen, ob keine Datums- oder Adresseinblendung im Bild steht (siehe `README.md`, Abschnitt Bilder).
